# 通用与专项边界

| 能力 | 能否通用 | 前提 |
|---|---|---|
| Android API30 Google APIs x64 AVD/ADB | 是 | 具体 App 的 APK 架构/最低 SDK/登录依赖另行核验 |
| APK 安装、启动、截图、UI XML 和日志证据 | 是 | 需要传入真实 package ID 和 APK |
| 受控四路 HTTP 服务与 404 真值记录 | 是 | 实际软件须能触发同源请求 |
| requests.json / HAR / Trace 结构与路由对账 | 可移植基线 | 导出格式不同时要写适配器；当前不是逐事件强一致验证 |
| AES-GCM 分段/独立密钥/公钥封装/可信 SHA | 是 | 接收端私钥只存在短期 Runner；可信 SHA 从独立渠道固定 |
| 19 条分段传输正反例 | 是 | 测试合成 ZIP，非替代被测项目自身验证 |
| 问题原编号及销项流程 | 是 | 保留各项目独立编号，不跨项目套用 Kiwi 编号 |
| 原生 Kiwi 内部菜单、特权页、DevTools、MSE/OPFS | 否 | 放在 Kiwi 专项工程 |
| R99/R100/R103 私有源码、安装包、个人流量数据 | 否 | 不属于此通用包 |

说明：本包只包含一份通用能力集合；项目自身的完整工程、历史原始证据另存，避免复制冗余附件。
