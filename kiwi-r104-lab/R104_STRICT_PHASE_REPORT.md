日期：2026-11-12。测试对象的正式业务版本仍为 MV2 V0.4.58。
本报告仅记录验收程序增强；没有修改私有插件 ZIP 中的任何业务代码。

## 继承基线（不重复销项）
- R103：正式插件真实 Android Kiwi 安装、侧栏显示、观察 UI、浏览器下载文件、ADB 回读 45,439B / 47 ZIP 条目 CRC 通过。
- R104 受控浏览器网络服务真实产生 28 次请求（四路径、七批次、200/404），Run 43164415061。
- R104 原 10 门对账仅证明四类路径覆盖；“同一路径缺一条事件”可能被误判通过。
- 原 R01–R40、F01–F15、T01–T54、R77-02、R88-01、R94-04、UX 原编号不变。

## 新增严格门
- STRICT_01：ZIP CRC/文件哈希
- STRICT_02：请求记录/HAR/Trace 结构唯一可定位
- STRICT_03：三份 JSON 解析
- STRICT_04：独立服务器真实请求窗口，四条路由与两个完整批次、200/404 正确
- STRICT_05：requests.json 每个路由和 seq 的数量与服务器**逐条一致**，状态不缺失
- STRICT_06：HAR 每个路由和 seq 的数量与服务器逐条一致，响应状态不缺失
- STRICT_07：Trace 每个路由和 seq 的数量与服务器逐条一致
- STRICT_08：三套记录与服务端逐事件一致；仅结构齐全不能 PASS

### 注意边界
该程序目前按 `current/Network/requests.json`、`network.har`、`Trace/trace.json` 里的常见 URL、status 数据结构做严格验证；正式 ZIP 的实际结构必须用真实导出核验。
部分 Trace 可能只记录事件而不保证一请求一事件；若发现该设计差异，应保留失败并开发有证据的适配器，不得降低原目标。
本轮**尚未在真实 Kiwi Android 上完成正式 MV2 的 28 次请求逐条对账**，所以 A7/NET 整项仍为 NOT_RUN/PARTIAL。
响应正文、媒体分轨和浏览器重启后持久化另做专项验证，不能因 STRICT_01～08 通过自动销项。
